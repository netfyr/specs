# Contributing specifications

Propose and review specifications in
[SpecDoc](https://specs.josie.cloud/?ns=netfyr%2Fspecs). Sign in with GitHub,
create a proposal or revise an existing note, and work through its review there.
See the [spec lifecycle](https://specdoc.josie.cloud/spec-lifecycle/) for approval,
publication, and revision steps. SpecDoc opens the publication pull request after
approval. A spec becomes authoritative once that pull request is merged.

Implementation pull requests belong in
[netfyr/netfyr](https://github.com/netfyr/netfyr), following
that repository's contribution guide.
